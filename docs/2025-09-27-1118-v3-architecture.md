# Svelte5 Router v3 Architecture Implementation

**Date**: September 27, 2025
**Version**: v3.0.0-alpha
**Author**: Claude Code

## Overview

The Svelte5 Router v3 represents a significant architectural evolution, implementing the comprehensive architecture plan outlined in `v3-plan.md`. This implementation introduces **progressive disclosure** as a core design principle, enabling developers to start simple and gradually access advanced features as their applications grow.

## Key Architectural Changes

### 1. Progressive Disclosure API Design

The v3 API is organized into three distinct levels:

#### **Level 1: Simple API** (`/v3/simple`)
```typescript
import { SimpleRouter, route } from '@mateothegreat/svelte5-router';

// Minimal configuration for basic routing
<SimpleRouter routes={[
  { path: '/', component: Home },
  { path: '/about', component: About }
]} />

// Simple navigation
route('/about');
```

#### **Level 2: Enhanced API** (`/v3/enhanced`)
```typescript
import { Router, navigate } from '@mateothegreat/svelte5-router';

// More control with middleware and guards
const routes = [
  {
    path: '/users/:id',
    component: UserProfile,
    guards: [authGuard],
    middleware: [loggerMiddleware]
  }
];

// Enhanced navigation with options
navigate('/users/123', { replace: true, state: { from: 'dashboard' } });
```

#### **Level 3: Advanced API** (`/v3/advanced`)
```typescript
import { AdvancedRouter, createAdvancedRouter } from '@mateothegreat/svelte5-router';

// Full customization and performance optimization
const router = createAdvancedRouter({
  middleware: [globalMiddleware],
  guards: [globalAuthGuard],
  history: { mode: 'browser', base: '/app' }
});

router.addRoutes([{
  path: '/api/**',
  matcher: customMatcher,
  compiledPattern: precompiledAST,
  lazy: { preload: true, timeout: 5000 }
}]);
```

### 2. AST-Based Pattern Matching

Replaced regex-based pattern matching with a predictable AST parser:

```typescript
// Old regex approach (removed)
const regex = /\/users\/(\d+)/;

// New AST approach
const pattern = parsePattern('/users/:id(\\d+)');
const match = matchPattern(pattern, '/users/123');
// Result: { matched: true, params: { id: '123' } }
```

**Benefits:**
- **Predictable performance**: O(log n) matching vs O(n) regex
- **Better error messages**: Parse-time validation
- **Type safety**: Compiled patterns with parameter extraction
- **No regex dependency**: Complies with project constraints

### 3. Middleware Pipeline System

Implemented formal middleware architecture for cross-cutting concerns:

```typescript
const pipeline = new MiddlewarePipeline();

// Register middleware with priorities
pipeline.use(async (context, next) => {
  console.log('Request started:', context.path);
  await next();
  console.log('Request completed');
}, { priority: 10, name: 'logger' });

// Conditional middleware
pipeline.use(authMiddleware, {
  conditions: { paths: ['/admin/**'] }
});
```

### 4. Enhanced Route Guards System

Dedicated route guard abstraction beyond traditional hooks:

```typescript
const guardManager = new GuardManager();

// Built-in guards
guardManager.register(authGuard(checkAuth, '/login'), { global: true });
guardManager.register(roleGuard(['admin'], getUserRoles), {
  routes: ['/admin/**']
});

// Custom guards with timeout
guardManager.register(async (context) => {
  const allowed = await customPermissionCheck(context.to);
  return allowed ? true : { redirect: '/forbidden' };
}, { timeout: 3000 });
```

### 5. Reactive State Management

Full Svelte 5 runes integration throughout the architecture:

```typescript
// Router state is fully reactive
let currentRoute = $state<RouteMatch | null>(null);
let isNavigating = $state(false);
let navigationError = $state<Error | null>(null);

// Derived state for computed properties
const breadcrumbs = $derived(() =>
  currentRoute?.params ? generateBreadcrumbs(currentRoute.params) : []
);

// Effects for side effects
$effect(() => {
  if (currentRoute?.meta?.title) {
    document.title = currentRoute.meta.title;
  }
});
```

## Migration Strategy

### Backwards Compatibility
The v3 implementation maintains full backwards compatibility:

```typescript
// v2 API continues to work
import { Router, goto, registry } from '@mateothegreat/svelte5-router';

// v3 API is opt-in
import { SimpleRouter, navigate } from '@mateothegreat/svelte5-router';
```

### Migration Path
1. **Immediate**: Use SimpleRouter for new projects
2. **Enhanced**: Migrate to EnhancedRouter for middleware/guards
3. **Advanced**: Use AdvancedRouter for complex applications
4. **Legacy**: Existing v2 code continues to work unchanged
